Before and after the final refinement

Our model ends each sequence with a 1500-iteration refinement of the map (colours, geometry and warp; camera poses are held). The paper's render table scores the map after that step, and the paper's runtime table leaves the step out. This page shows both tables both ways, so quality and speed can be read for the same system. Benchmark runs of 9 November (old code), one run per sequence, seed 0, NVIDIA A100.

Cost of the online inputs

Our model computes its own inputs for every frame as it arrives: optical flow, instance segmentation, and the moving-region masks and tool motion built from them. A second thread computes them for frame t while frame t−1 is tracked and mapped, so most of that work overlaps the loop. The runtime table counts only the time the loop had to wait for them (inside Tracking).

  • Stereo depth (FoundationStereo) is precomputed and given to every method; its time was not measured and is in no row for any method.
